# ❖ Bedrock Workshop - Fusor de Addons (PT-BR)

Ferramenta web 100% client-side (roda direto no navegador, sem enviar arquivos para servidores) para unir múltiplos addons de **Minecraft Bedrock** (`.mcaddon`, `.mcpack`, `.zip`) em um único pacote instalável.

### ✨ Funcionalidades
- **Separação automática** de Behavior Packs (BP) e Resource Packs (RP).
- **Organização em pastas** individuais por bloco e item (`blocks/nome_bloco/`).
- **Unificação de traduções** consolidando tudo em `pt_BR.lang` e `en_US.lang`.
- **Fusão de JSONs críticos** (`terrain_texture.json`, `item_texture.json` e `blocks.json`).
- **Geração automática de `manifest.json`** com novos UUIDs e suporte a scripts (`@minecraft/server`).
